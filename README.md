# Task Manager API A clean and structured RESTful API built with Node.js and Express.js. This project focuses on backend architecture, middleware design, and clean code practices using MongoDB as the database layer. --- ## 🚀 Features - RESTful API structure - MongoDB integration - Environment variables support (.env) - Clean architecture (Controllers / Routes / Middlewares) - Centralized error handling - Request logging middleware - Input validation middleware - Async error handling wrapper - 404 Not Found handler - Unified API response format --- ## 🧱 Project Structure  
bash``` project-root/ ├── controllers/ │ └── task.controller.js │ ├── routes/ │ └── task.routes.js │ ├── middlewares/ │ ├── logger.middleware.js │ ├── validateTask.middleware.js │ ├── asyncWrapper.middleware.js │ ├── errorHandler.middleware.js │ └── notFound.middleware.js │ ├── models/ │ └── task.model.js │ ├── config/ │ └── db.js │ ├── .env ├── app.js ├── server.js └── package.json --- ##   ``` ⚙️ Technologies Used - Node.js - Express.js - MongoDB - Mongoose - dotenv --- ## 🔐 Environment Variables Create a `.env` file in the root directory and add: env``` PORT=3000 MONGO_URI=mongodb_connection_string ``` --- ## 📌 API Endpoints ### Tasks | Method | Endpoint | Description | |--------|----------------|-----------------| | GET | /api/tasks | Get all tasks | | GET | /api/tasks/:id | Get task by ID | | POST | /api/tasks | Create task | | PUT | /api/tasks/:id | Update task | | DELETE | /api/tasks/:id | Delete task | --- ## 📦 Middlewares ### Logger Middleware Logs incoming HTTP requests. ### Validation Middleware Validates request body before processing. ### Async Wrapper Handles async errors and forwards them to error handler. ### Error Handler Centralized error handling for all API responses. ### Not Found Handler Handles undefined routes (404 responses). --- ## 🔄 Response Format ### json``` Success Response { "success": true, "data": {}, "message": "Operation successful" }``` ### Error Response json``` { "success": false, "message": "Error message" } ```--- ## 🧠 Key Concepts Demonstrated - Middleware lifecycle in Express - Separation of concerns - Clean architecture design - Async error handling strategy - MongoDB integration with Node.js - Environment configuration management --- ## 📌 Notes -
